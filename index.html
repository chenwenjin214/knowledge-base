怎么加一篇新文章

整个流程只有三步,一分钟搞定,连命令行都不用碰。

  1. 在 pages/ 文件夹里新建一个 xxx.html,内容照抄现有的这篇,把标题、正文、href="../assets/style.css" 和 href="../index.html" 改掉就行
  2. 回到 index.html,在 <div class="kb-grid"> 里复制一段 <a class="kb-card">,改掉 href 和标题
  3. 在 GitHub 网页上点 Commit changes 提交 —— 几十秒后线上自动更新,不用重新部署任何东西
